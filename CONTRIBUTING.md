# Contributing

This repository publishes the Recipes and examples for the Hive Axyl SDK for Unity. They are developed and reviewed
internally at Com2uS Platform, and published content is not edited here directly.

## GitHub Issues are not used

Questions, bug reports, and feature requests are not accepted through GitHub Issues. Send them to
<cs-platform@com2us.com> (see [Support](README.md#support) in the README). GitHub is not an official customer support
channel, and we do not commit to response or resolution timelines.

## External pull requests are not accepted

External pull requests are not a contribution path. We do not review or merge them, and any that are opened will be
closed with a pointer to the support channels above. If you have a suggestion for a Recipe or an example, send it
through those channels and the owning team will review it.

Pull requests created by our release automation (**promotion pull requests**) are not external contributions. They
carry internally approved changes and are how the published content of this repository changes. Only the automation
creates and merges them.

## Security vulnerabilities

Do not report them through public issues or pull requests. The private channel documented in
[SECURITY.md](SECURITY.md) is the only intake path.
