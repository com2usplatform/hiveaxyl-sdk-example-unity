# Security Policy

## Supported versions

The latest published version is supported. We do not ship separate security fixes for earlier versions;
fixes are delivered in the next published version.

## Reporting a vulnerability

**Do not report security issues through public GitHub issues, pull requests, or discussions.** GitHub
Issues are disabled in this repository, so the private channel below is the only intake path.

| Channel | Address |
| --- | --- |
| Private vulnerability report | <cs-platform@com2us.com> |

Including the following helps us confirm a report quickly:

- Affected Recipe or example, and the SDK version it was used with
- Platform (Android, iOS, macOS, Windows, WebGL) and Unity version
- Reproduction steps and the minimum environment needed
- Expected impact
- Any mitigation you are aware of

A vulnerability in the SDK itself can be reported through the same channel.

## What happens next

Reports are handled under Com2uS Platform's security incident response process. We acknowledge receipt
and share progress through the intake channel you used. Nothing about a report appears in this
repository until a fix is published.

We do not commit to response or resolution timelines.
